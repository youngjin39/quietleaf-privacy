개인정보처리방침 (Privacy Policy)

발효일: 2026-10-07

1. 수집하는 정보

QuietLeaf는 데이터를 수집하거나 공유하지 않으며, 네트워크에 연결하지 않습니다. 개발자가 운영하는 서버도 없습니다.

앱이 기기에 저장하는 데이터:

  • 사용자가 가져온 문서의 앱 전용 사본과 제목
  • 읽기 위치, 북마크와 메모, 컬렉션, 검색 기록, 앱 설정

위 데이터는 기기에만 저장되며 외부 서버로 전송되지 않습니다. 사용자가 직접 만든 로컬 백업 파일은 사용자가 고른 위치에 저장됩니다.

2. 무료 이용

QuietLeaf는 완전 무료 앱입니다. 책 수 제한, 인앱 구매, 구매 복원 기능이 없습니다.

앱은 Google Play 결제 라이브러리를 사용하지 않으며, 구매 내역을 조회하거나 구매 확인 정보를 처리하지 않습니다.

3. 이전 버전의 구매 상태 파일

이전 버전에서 기기에 저장한 entitlement.json과 entitlement.backup.json 파일은 그대로 두며, 현재 앱은 이 파일을 읽거나 사용하지 않습니다.

4. 제3자 서비스

QuietLeaf는 광고, AdMob, 분석, 계정, 동기화 서비스를 사용하지 않으며, 광고 식별자를 사용하거나 사용 통계를 수집하지 않습니다.

음성 읽기는 기기에 설치된 오프라인 음성을 사용합니다.

5. 앱 권한과 인터넷

  • 배포용 앱에는 결제(BILLING), 인터넷(INTERNET), 네트워크 상태(ACCESS_NETWORK_STATE) 권한이 없습니다.
  • 앱 자체의 비공개 동적 수신기 권한(com.quietleaf.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION)만 선언합니다. 이 권한은 다른 앱이 비공개 수신기에 접근하지 못하도록 제한합니다.
  • 앱은 네트워크에 연결하지 않으며, 문서 안의 인터넷 이미지 주소도 불러오지 않습니다. 모든 읽기 기능은 오프라인으로 동작합니다.

6. 파일 접근 권한

문서는 Android 시스템 파일 선택기 또는 공유 메뉴를 통해 사용자가 직접 선택합니다. QuietLeaf는 선택된 항목을 앱 전용 저장소로 복사하며 광범위한 저장소 권한을 요청하지 않습니다.

7. 데이터 삭제

라이브러리에서 문서를 삭제하면 해당 앱 전용 사본과 연결된 읽기 위치·북마크가 삭제됩니다. 앱 데이터를 지우거나 앱을 삭제하면 앱 전용 저장소의 문서와 상태, 이전 버전에서 남은 파일도 함께 삭제됩니다. 사용자가 별도로 저장한 로컬 백업 파일은 해당 위치에서 직접 삭제할 수 있습니다.

개발자는 사용자 데이터를 보관하지 않으므로 별도로 삭제를 요청할 데이터가 없습니다.

8. 어린이 개인정보

QuietLeaf는 13세 미만 어린이를 대상으로 하지 않으며, 어린이의 개인정보를 의도적으로 수집하지 않습니다.
